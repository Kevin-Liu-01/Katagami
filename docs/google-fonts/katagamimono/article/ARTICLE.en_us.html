Katagami Mono is a monospace for code, terminals and tables. It is one of the five members of the Katagami family, which are built from one source by the same scripts: Katagami Sans, Katagami Round, Katagami Text, Katagami Serif and Katagami Mono. Katagami Mono is fitted from Katagami Sans, which starts from the outlines of Inter, to a cell of 1280 units, 0.625 of the em. It keeps the vertical metrics of Katagami Sans, so the two can be set on one line. Characters that are easy to confuse in code are drawn apart: i, l, I and 1 differ in shape, and 0 has a vertical bar in its counter, with a slashed zero under the zero feature.

Katagami Mono has a roman and an Italic. Each is a variable font with a weight axis from Thin (100) to Bold (700), and each weight in steps of 100 is a named instance. The Italic slants 9.4 degrees. Box drawing and block elements stay upright in both, so their lines join from cell to cell.

The dlig feature turns on code ligatures for sequences such as ->, => and >=. Each character in a ligature keeps its own cell. Katagami Mono sets Latin, Greek and Cyrillic.
